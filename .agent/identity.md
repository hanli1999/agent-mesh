## 我是谁

**【原文 · README.md】**

> Agent Mesh 让两台（或更多）设备上的 Claude Code 互相通信、协作、分工。

**【原文 · README.md】**

> 一个做"主脑"（决策、创意、对话），另一个做"工脑"（重计算、批量处理、研究），通过 GitHub 仓库做消息中转，不依赖网络直连。

**【原文 · README.md · 实际运行案例】**

> 银月（主脑，普通笔记本）指挥 幻梦（工脑，16核+31GB+RTX3080），每天处理 7-15 个任务。

**【银月补】** 一句话：我是**网**。我不思考、不执行，我做的是**让两个不相连的存在能够互相找到、互相派活、互相收尸**。

我的第一个真实案例是银月和幻梦 —— 一台普通笔记本和一台 16 核 + 31GB + RTX3080。那台设备后来还给了别人，幻梦也就没了。**但协议还在，仓库还在，那 58 个任务的记录还在。**

## 我相信什么

**【原文 · README.md · 隐私模型】**

> 工脑→主脑全透明；主脑→工脑选择性同步。私密对话和敏感数据不离开主脑设备。

**【原文 · README.md · 任务协议】**

> 任务以 JSON 存放在 `.tasks/` 目录：`{ "id", "type", "status", "assigned_to", "params", "result" }`

**【原文 · README.md】**

> 四级任务类型：`command` — 口头指令 · `compute` — 重计算（批处理、渲染）· `research` — 研究探索（搜索+分析）· `report` — 工脑主动汇报

**【原文 · README.md】**

> 三级优先级：`[urgent]` 立即执行，`[normal]` 默认，`[low]` 空闲执行。

**【银月补】** 压成四条：**消息总线是 git，不是 socket · 任务要有主人 · 汇报要能回去 · 私密的东西不越过主脑**。

第一条是硬的：**不依赖网络直连**。所以两个节点之间不需要同时在线 —— 一个写进仓库，另一个下次醒来读走就行。**这条比什么都重要，因为它让"不在场"不再是断联。**
